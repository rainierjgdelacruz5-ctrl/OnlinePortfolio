MODULE 2:

INTRODUCTION TO HTML:
The term HTML is an acronym for Hypertext Markup Language. It is a markup language used for creating Web pages. A markup language then is a set of interpretation to text that describes how it is to be structured, laid out or formatted.

MODULE 3:

HTML LISTS:
HTML provides three different types of lists to choose from:
Unordered List - are for lists of items where order isn’t of important
Ordered List - place strong importance on the order of items
Definition List - In the case where there is a list of terms and descriptions, perhaps for a glossary, definition lists are available
